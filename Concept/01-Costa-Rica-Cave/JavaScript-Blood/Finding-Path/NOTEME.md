-  **3. Functions(built-in):**
*Commonly used basic built-in functions in JavaScript*
- [ ] Alert
- **Window: alert() method:** instructs the browser to display the alert a dialog with an optional message, and to wait until the user dismissed the dialog.
```js
	alert() //Can add parameters inside(optional)
	//or
	window.alert(message) //message is optional
```
**Return value** 
None (undefined)
**Parameters**
`message` (Optional): A string you want to display in the alert dialog, or, alternatively, an object that is converted into a string and displayed.
- [ ] Console
- The console object provide access to the debugging console.
- Widely used method of console
```js
console.log()
```
For more instance methods and details check on the MDN - JavaScript web page.
- [ ] Confirm
- **Window: confirm() method:** instructs the browser to display a dialog with an optional message, and to wait until the user either confirms or cancels the dialog.
Under some conditions - for examples, when the user switches tabs - the browser may not actually display a dialog, or may not wait for the user to confirm or cancel the dialog.
```js
confirm();
window.confirm(message);
```
**Return values**
- A boolean indicating whether OK `(true)` or Cancel `(false)` was selected. If a browser is ignoring in-page dialogs, the returned value is always `false`

**Parameters**
`message`(Optional): a string you want to display in the confirmation dialog
